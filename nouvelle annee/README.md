# 🎆 Bonne Année 2026 — AdenCode

Une page web **interactive, moderne et élégante** pour souhaiter la **Bonne Année 2026**, développée avec **HTML, CSS et JavaScript pur**, incluant animations, compte à rebours et effets visuels de nouvelle génération.

---

## ✨ Aperçu du projet

Cette page a été conçue pour :
- Souhaiter une **bonne année personnalisée** à la famille et aux amis
- Mettre en avant une **identité visuelle professionnelle**
- Montrer des compétences en **frontend moderne**
- Créer une expérience immersive avec animations 🎇

---

## 🚀 Fonctionnalités

- 🎨 **Design futuriste** avec fond animé (gradient dynamique)
- 🧊 **Glassmorphism UI** (effet carte en verre)
- ⏳ **Compte à rebours en temps réel** jusqu’au 1er janvier 2026
- 🎆 **Feux d’artifice animés** en Canvas
- 🖼️ **Logo visible à gauche** (branding AdenCode)
- 👤 **Section propriétaire** (photo + nom + rôle)
- 📱 **Responsive** (mobile & desktop)
- ⚡ **Aucune librairie JS externe**

---

## 🛠️ Technologies utilisées

- **HTML5**
- **CSS3**
  - Animations
  - Media queries
  - Glassmorphism
- **JavaScript Vanilla**
  - Countdown dynamique
  - Canvas Fireworks
- **Google Fonts**
  - Space Grotesk
